# TaskFlow – Smart Project Management SaaS

TaskFlow is a responsive project management website designed to help users manage their projects efficiently.

## Features

- Responsive Navigation Bar
- Hero Section
- Features Section
- About / How It Works
- Free and Pro Pricing Plans
- Contact Form
- Smooth Scrolling
- Mobile Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

- index.html
- style.css
- script.js

## Project Objective

To create a simple and user-friendly project management website using front-end technologies.
